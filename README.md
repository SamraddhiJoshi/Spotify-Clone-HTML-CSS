# Spotify Clone

A responsive Spotify-inspired music player UI built using pure HTML and CSS.

## Features

- Modern Spotify-like interface
- Responsive sidebar navigation
- Music player section
- Album and playlist cards
- Hover effects and smooth UI
- Fully responsive layout
- Pure HTML & CSS project

## Technologies Used

- HTML5
- CSS3
- Font Awesome
- Google Fonts

## Folder Structure

```bash
CSS_SpotifyClone/
│
├── assets/
├── index.html
└── style.css
```
